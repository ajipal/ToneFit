# Autumn Season — Outfit Photos

Place sample outfit photos for the **Autumn** personal color season here.

## Who is an Autumn?
- Undertone: **Warm**
- Skin: Deep, muted, earthy or golden-olive
- Features: Rich, warm coloring; auburn, dark brown, or warm black hair
- Examples: Kathryn Bernardo, Beyoncé, Jennie (BLACKPINK), V/Taehyung, Nadine Lustre

## What photos to add
Add `.jpg` or `.png` images of outfits that flatter Autumn coloring.
Aim for **3–6 photos** across casual, smart casual, and formal styles.

> **Note:** Autumn is historically the hardest season to predict in ML models.
> Good outfit examples can help users understand and validate their result.

## Color palette to follow
| Category | Colors |
|----------|--------|
| Tops | Rust, burnt orange, olive green, mustard, terracotta |
| Bottoms | Camel, chocolate brown, dark olive, warm tan |
| Outerwear | Deep camel, rich burgundy, forest green |
| Avoid | Icy blue, cool pink, stark white, electric neon |

## Outfit ideas
- **Casual**: Olive green tee, rust jeans, camel jacket
- **Smart Casual**: Burnt orange blouse with chocolate brown trousers
- **Formal**: Deep emerald gown, rich burgundy suit

## File naming
Use descriptive names so the team knows what each photo shows:
```
autumn_casual_olive_rust.jpg
autumn_smartcasual_burntorange_blouse.jpg
autumn_formal_emerald_gown.jpg
```

## Where photos appear in the app
These images are displayed in the **Outfits tab** of the ToneFit app
when a user is predicted as an Autumn season.
