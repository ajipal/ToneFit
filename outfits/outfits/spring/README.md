# Spring Season — Outfit Photos

Place sample outfit photos for the **Spring** personal color season here.

## Who is a Spring?
- Undertone: **Warm**
- Skin: Light, clear, peachy or golden
- Features: Bright eyes, warm hair (golden blonde, light auburn, honey brown)
- Examples: IU, Yoona, Emma Stone, Ariana Grande, Anne Curtis

## What photos to add
Add `.jpg` or `.png` images of outfits that flatter Spring coloring.
Aim for **3–6 photos** across casual, smart casual, and formal styles.

## Color palette to follow
| Category | Colors |
|----------|--------|
| Tops | Peach, coral, warm turquoise, ivory, light salmon |
| Bottoms | Camel, warm beige, cream, light tan |
| Outerwear | Champagne, warm white, light camel |
| Avoid | Cool gray, icy blue, stark black, cool purple |

## Outfit ideas
- **Casual**: Light floral prints, peach tones, warm whites
- **Smart Casual**: Coral blouse with cream trousers, warm beige blazer
- **Formal**: Champagne gold gown, warm ivory suit

## File naming
Use descriptive names so the team knows what each photo shows:
```
spring_casual_floral_dress.jpg
spring_smartcasual_coral_blouse.jpg
spring_formal_champagne_gown.jpg
```

## Where photos appear in the app
These images are displayed in the **Outfits tab** of the ToneFit app
when a user is predicted as a Spring season.
