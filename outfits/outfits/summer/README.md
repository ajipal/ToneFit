# Summer Season — Outfit Photos

Place sample outfit photos for the **Summer** personal color season here.

## Who is a Summer?
- Undertone: **Cool**
- Skin: Light, muted, ashy or rosy
- Features: Soft, muted coloring; ashy or cool-toned hair
- Examples: Taylor Swift, Nicole Kidman, Son Ye-jin, Taeyeon, Jodi Sta. Maria

## What photos to add
Add `.jpg` or `.png` images of outfits that flatter Summer coloring.
Aim for **3–6 photos** across casual, smart casual, and formal styles.

## Color palette to follow
| Category | Colors |
|----------|--------|
| Tops | Lavender, dusty rose, powder blue, mauve, soft gray |
| Bottoms | Light gray, dusty blue, soft white, cool beige |
| Outerwear | Sage green, soft lilac, cool gray |
| Avoid | Warm orange, mustard yellow, olive green, bright neon |

## Outfit ideas
- **Casual**: Dusty rose top, soft gray jeans, powder blue linen
- **Smart Casual**: Mauve blazer with light gray trousers, lavender blouse
- **Formal**: Dusty blue gown, soft lavender suit

## File naming
Use descriptive names so the team knows what each photo shows:
```
summer_casual_dustyrose_top.jpg
summer_smartcasual_mauve_blazer.jpg
summer_formal_dustyblue_gown.jpg
```

## Where photos appear in the app
These images are displayed in the **Outfits tab** of the ToneFit app
when a user is predicted as a Summer season.
